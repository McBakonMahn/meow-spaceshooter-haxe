# Building

You need HaxeFlixel with flixel-addons installed. You can install it by following [this official tutorial](https://haxeflixel.com/documentation/getting-started/).
you basically go through all steps except running hello world lol. easy

you go into the repo root folder and run in a terminal/command line. Target can be anything (e.g `linux`, `html5`. `windows`, `neko`, etc.). im pretty sure they explain it on their docs. 
```sh
lime build <target>
```

if you wanna test (build and run) you do
```sh
lime test <target>
```
if you wanna run without building (running previous build):
```sh
lime run <target>
```

Feel free to explore this thing and modify it.
